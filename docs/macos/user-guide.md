# Mac 阅读助手使用说明

## 小助手和对话

拖动小助手改变位置；点击展开或收起对话，展开位置跟随图标并保持在屏幕内。背景略微透出桌面，文字保持清晰。隐藏小助手后，可从菜单栏恢复。

收起对话不停止正在生成的回答。退出应用会停止采集和请求，已经保存的内容保留；异常重开会显示中断，不会自动再调用模型。

## 划词和读屏

自动划词默认关闭。先在设置确认采集说明，再允许辅助功能并开启划词。阅读区域不兼容时，可以改用手动读屏，不需要复制整篇文件。

外部引用支持累积和仅最新两种模式。仅最新模式下，明确取消源文档选区会移除对应引用；切入助手输入框会保留引用。AI 回答中的引用独立保留一条，可以与外部引用同时使用。

读屏默认框选区域，也可选择一个窗口。再次按读屏快捷键或按 Esc 可取消当前截取，原有输入不会丢失。截图进入草稿后可以预览或移除，不会自动上传。

读屏快捷键默认为 Shift+A，可在设置内修改或清除。冲突时保留原绑定；录入只在本应用内进行，不监听全局键盘文本。

## 模型与回答

模型和思考强度直接在输入区切换。带图片的问题使用支持图像的 Flash；选择文字模型时会明确提示，不会自动替换模型或删除图片。

复制、引用、追问和重新生成位于回答下方。追问只引用并聚焦输入框，不自动发送。重新生成会再次产生 API 用量，失败时保留原回答。设置改变只影响后续请求，重试使用原先冻结的资料。

## 权限、数据和更新

系统设置中的“隐私与安全性”分别管理辅助功能与屏幕访问。拒绝一项权限不影响手动文字对话。应用只在你触发读屏时截取，不扫描整个 PDF，不保存剪贴板历史。

数据保存在 `~/Library/Application Support/com.decous.anysidebar.mac/`；Key 位于系统钥匙串的 `com.decous.anysidebar.mac.deepseek` 项，和 Chrome 插件的数据分开。删除全部任务保留 Key 与偏好，清除 Key 保留对话。

本机文件没有额外加密，设备及账户保护仍很重要。用户发送时，问题、引用、截图和相关历史直接提交 DeepSeek 官方 API，没有第三方中转或后台统计。

开发者可配置 Any Sidebar 专用本机签名，让后续构建沿用同一钥匙串身份，减少更新导致的权限失效。不要删除对应签名证书和私钥；更换身份后仍可能需要重新授权。该签名仅用于本机开发，面向他人分发前仍需 Developer ID 签名、公证及相应验证。

仅有截图时可以直接发送，无需输入文字；此时默认解读图片内容。Shift+A 会占用输入大写 A 的组合，可以在设置修改或清除。

Shift+S 用于展开或收起浮窗，Shift+A 用于读屏或取消截取，两项可分别修改。左上角的会话抽屉用于新建和切换会话；设置页左上角箭头返回对话。
